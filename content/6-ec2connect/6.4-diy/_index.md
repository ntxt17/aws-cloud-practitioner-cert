{{% notice info %}}

After completing the lab, the player does **DIY**

{{% /notice %}}


1. Select **DIY**

![DIY](/images/6-ec2connect/6.4-diy/0001-diy.png)

2. In the **DIY** interface

- Read **DIY ACTIVITIES**
- Read **SOLUTION VALIDATION METHOD**

![DIY](/images/6-ec2connect/6.4-diy/0002-diy.png)

3. For this **DIY**, we do **To change the instance type for a new instance configuration**

- Go to the AWS Console page, find and select **EC2**

![DIY](/images/6-ec2connect/6.4-diy/0003-diy.png)

3. In **EC2** interface

- Select **Instances**
- Select **Launch instances**

![DIY](/images/6-ec2connect/6.4-diy/0004-diy.png)

4. In **Choose an Amazon Machine Image (AMI)**

- Select **Amazon Linux 2 AMI (HVM) - Kernel 5.10, SSD Volume Type**
- Select **Select**

![DIY](/images/6-ec2connect/6.4-diy/0005-diy.png)

5. In **Choose an Instance Type**

- Select **m4.large**
- Then, select **Next: Configure Instance Details**

![DIY](/images/6-ec2connect/6.4-diy/0006-diy.png)

6. In **Configure Instance Details**

- Select **VPC**
- Select **subnet**
- Select **Next: Add Storage**

![DIY](/images/6-ec2connect/6.4-diy/0007-diy.png)

7. In **Add Storage**, select **Next: Add Tags**

![DIY](/images/6-ec2connect/6.4-diy/0008-diy.png)

8. In **Add Tags**, Select **Next: Configure Security Group**

![DIY](/images/6-ec2connect/6.4-diy/0009-diy.png)

9. In **Configure Security Group**

- Select **Select an existing security group**
- Select **Security Group ID**
- Select **Review and Launch**

![DIY](/images/6-ec2connect/6.4-diy/00010-diy.png)

10. In **Review Instance Launch**

- Check again and select **Launch**

![DIY](/images/6-ec2connect/6.4-diy/00011-diy.png)

11. In **Select an existing key pair or create a new key pair**

- Select **Proceed without a key pair**
- Select **I acknowledge...**
- Select **Launch Instances**

![DIY](/images/6-ec2connect/6.4-diy/00012-diy.png)

12. Select **View Instances**

![DIY](/images/6-ec2connect/6.4-diy/00013-diy.png)

13. Copy **Instance ID**

![DIY](/images/6-ec2connect/6.4-diy/00014-diy.png)

14. In the **DIY** interface
- Paste **Instance ID** into **VALIDATION FORM**
- Then select **VALIDATE**

![DIY](/images/6-ec2connect/6.4-diy/00015-diy.png)

15. After selecting **VALIDATE**

- **VALIDATION MESSAGE** displays **Success!**
- Then select **EXIT**

![DIY](/images/6-ec2connect/6.4-diy/00016-diy.png)

16. In **ASSIGNMENT** select **COLLECT**

![DIY](/images/6-ec2connect/6.4-diy/00017-diy.png)

17. Select **NEXT**

![DIY](/images/6-ec2connect/6.4-diy/00018-diy.png)

18. Select **COLLECT**

![DIY](/images/6-ec2connect/6.4-diy/00019-diy.png)
    
19. Congratulations on completing Assignment 3

![DIY](/images/6-ec2connect/6.4-diy/00020-diy.png)

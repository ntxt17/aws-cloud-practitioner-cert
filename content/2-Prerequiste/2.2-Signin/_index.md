There are 4 options for logging into **AWS Training and Certification**:

- Login with Amazon
- AWS Partner
- Organization SSO
- Amazon Employee
  
{{% notice note %}}
This lab uses the **Login with Amazon** login method.
{{% /notice %}}

Steps to sign in to **AWS Training and Certification**

1. Go to [AWS Skill Builder](https://explore.skillbuilder.aws/learn/signin)
2. Select **SIGN IN TO AWS SKILL BUILDER**

![Login](/images/2.prerequisite/2.2-Signin/0001-Signin.png)

3. The **AWS Training and Certification** login interface appears, select **Login with Amazon**

![Login](/images/2.prerequisite/2.2-Signin/0002-Signin.png)

4. Amazon login page appears:

- Enter **Email or mobile phone number**
- Enter **Password**
- Then, select **Sign-in**


![Login](/images/2.prerequisite/2.2-Signin/0003-Signin.png)

5. After logging in, the **AWS Training and Certification** interface appears.

![Login](/images/2.prerequisite/2.2-Signin/0005-Signin.png)

{{% notice note %}}
Note: During the login process, as shown in the picture, select **Allow**
{{% /notice %}}


![Login](/images/2.prerequisite/2.2-Signin/0004-Signin.png)

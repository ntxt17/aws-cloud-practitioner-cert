{{% notice info %}}

After completing the lab, the player does **DIY**

{{% /notice %}}

1. In the **DIY** interface
- Read **DIY ACTIVITIES**
- Read **SOLUTION VALIDATION METHOD**

![DIY](/images/8-awspricingcalculator/8.4-diy/0000-diy.png)

2. Go to the [AWS Pricing Calculator](https://calculator.aws/#/)

- Select **Create estimate**
  
![DIY](/images/8-awspricingcalculator/8.4-diy/0001-diy.png)

3. In **My Estimate**

- Select **Add group**
  
![DIY](/images/8-awspricingcalculator/8.4-diy/0003-diy.png)

4. In **Add group**
- **Group name**, enter ```Web Servers```
- Select **Add group**

![DIY](/images/8-awspricingcalculator/8.4-diy/0004-diy.png)

5. In the **Web Servers** interface
- Select **Add service**
  
![DIY](/images/8-awspricingcalculator/8.4-diy/0005-diy.png)

6. In **Add service**

- Search **EC2**
- Select **Configure**

![DIY](/images/8-awspricingcalculator/8.4-diy/0006-diy.png)

7. In **Configure Amazon EC2**
- **Description**, enter ```Web Server Estimate```
- **Region**, select **US East (N. Virginia)**
- In **EC2 instance specifications**, select **Linux**
![DIY](/images/8-awspricingcalculator/8.4-diy/0007-diy.png)

8. In the **Workload** interface
- Select **Daily spike traffic**
- **Daily spike pattern**, **Workload days** section, choose the days of the week
- **Baseline**, enter ```2```
- **Peak**, enter ```4```
- **Duration of peak**, enter ```8``` and ```0```

![DIY](/images/8-awspricingcalculator/8.4-diy/0008-diy.png)

9. In **EC2 Instances**
- Select **t2.micro**

![DIY](/images/8-awspricingcalculator/8.4-diy/0009-diy.png)

10. In **Pricing strategy**

- **Pricing model**, select **On-demand**
- Select **Show calculations**
- Select **estimate workload hours**
  
![DIY](/images/8-awspricingcalculator/8.4-diy/00010-diy.png)

11. In **Amazon Elastic Block Storage (EBS)**

- **Storage for each EC2 instance**, select **General Purpose SSD (gp2)**
- **Storage amount**, enter ```30```
- **Snapshot Frequency**, enter ```Weekly```
- **Amount changed per snapshot**, enter ```1```
  
![DIY](/images/8-awspricingcalculator/8.4-diy/00011-diy.png)

12. View results **Estimated workload hours**

![DIY](/images/8-awspricingcalculator/8.4-diy/00012-diy.png)

13. In **Data Transfer**
- **Inbound Data Transfer**, select **Internet (free)**
- Select ```1```
- Select **TB per month**
- **Outbound Data Transfer**, select **Internet ($0.05 - $0.09 per GB)**
- Select ```100```
- Select **TB per month**
  
![DIY](/images/8-awspricingcalculator/8.4-diy/00013-diy.png)

14. Select **Show calculations**

- View and select **Add to my estimate**

![DIY](/images/8-awspricingcalculator/8.4-diy/00014-diy.png)

15. In the **Web Servers** interface

- Select **Share**

![DIY](/images/8-awspricingcalculator/8.4-diy/00015-diy.png)

16 In the **Save estimate** interface

- Select **Copy public link**

![DIY](/images/8-awspricingcalculator/8.4-diy/00016-diy.png)

17. After **Copy public link**
- Enter the **DIY** interface
- Paste in **VALIDATION FORM**
- Select **VALIDATE**
- On **VALIDATION MESSAGE**, appearing **Great job!...** is completed **DIY**
- Then select **EXIT** to exit
  
![DIY](/images/8-awspricingcalculator/8.4-diy/00017-diy.png)

18. After the city interface

- Go to **ASSIGNMENT**, select **COLLECT**

![DIY](/images/8-awspricingcalculator/8.4-diy/00018-diy.png)

19. Select **NEXT**

![DIY](/images/8-awspricingcalculator/8.4-diy/00019-diy.png)

20. Select **COLLECT**

![DIY](/images/8-awspricingcalculator/8.4-diy/00020-diy.png)

21. Congratulations to the player receiving the reward

![DIY](/images/8-awspricingcalculator/8.4-diy/00021-diy.png)

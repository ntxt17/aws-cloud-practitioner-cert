After the city interface appears, we build the player profile

1. Click on the profile picture to go to the **Custom Profile** page

![Build Profile](/images/3-AWSCloudQuest/3.2-CustomProfile/0001-customprofile.png?width=90pc)

2. In **Custom Profile** page

![Build Profile](/images/3-AWSCloudQuest/3.2-CustomProfile/0002-customprofile.png?width=90pc)

3. Select **EDIT/VIEW** to perform player naming

- At least 3 characters
- Up to 25 characters
- Only letters and numbers
- '_' and ''
- No leading or trailing whitespace

4. Select **ACCEPT**

![Build Profile](/images/3-AWSCloudQuest/3.2-CustomProfile/0003-customprofile.png?width=90pc)

5. Section **Body Options**

- Select **Body type**
- Select **Skin color**
- Select **Height**
- Select **Composition**
- Select **Shape**
- Select **Head size**

![Build Profile](/images/3-AWSCloudQuest/3.2-CustomProfile/0004-customprofile.png?width=90pc)

6. Head Options

- Select **HAIR STYLES**
- Select **FACIAL HAIR**
- Select **EYE COLOR**

![Build Profile](/images/3-AWSCloudQuest/3.2-CustomProfile/0005-customprofile.png?width=90pc)

7. The **Clothing** section

- Select **Choose your style!**
- Select ***TOPS**
- Select **BOTTOMS**
- Select **SHOES**
- Select **HATS**
- Select **ACCESSORIES**


![Build Profile](/images/3-AWSCloudQuest/3.2-CustomProfile/0006-customprofile.png?width=90pc)

8. Select **SAVE**

9. Moving Guide

- Use keys A(turn left) - W(forward) - S(backward) - D(turn right)
- Choose tools as shown to experience the game
- Use Shift to skateboard
- Use mouse pointer to zoom and rotate


![Build Profile](/images/3-AWSCloudQuest/3.2-CustomProfile/0007-customprofile.png?width=90pc)

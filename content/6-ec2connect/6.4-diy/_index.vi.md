{{% notice info %}}

Sau khi hoàn thành bài lab, người chơi thực hiện **DIY**

{{% /notice %}}


1. Chọn **DIY** 

![DIY](/images/6-ec2connect/6.4-diy/0001-diy.png)

2. Trong giao diện **DIY**

- Đọc  **DIY ACTIVITIES**
- Đọc **SOLUTION VALIDATION METHOD**

![DIY](/images/6-ec2connect/6.4-diy/0002-diy.png)

3. Đối với **DIY** này, ta thực hiện **To change the instance type for a new instance configuration**

- Vào trang AWS Console, tìm và chọn **EC2**

![DIY](/images/6-ec2connect/6.4-diy/0003-diy.png)

3. Trong giao diện **EC2**

- Chọn **Instances**
- Chọn **Launch instances**

![DIY](/images/6-ec2connect/6.4-diy/0004-diy.png)

4. Trong **Choose an Amazon Machine Image (AMI)**

- Chọn **Amazon Linux 2 AMI (HVM) - Kernel 5.10, SSD Volume Type**
- Chọn **Select**

![DIY](/images/6-ec2connect/6.4-diy/0005-diy.png)

5. Trong **Choose an Instance Type**

- Chọn **m4.large**
- Sau đó, chọn **Next: Configure Instance Details**

![DIY](/images/6-ec2connect/6.4-diy/0006-diy.png)

6. Trong **Configure Instance Details**

-  Chọn **VPC**
-  Chọn **subnet**
-  Chọn **Next: Add Storage**

![DIY](/images/6-ec2connect/6.4-diy/0007-diy.png)

7. Trong **Add Storage**, chọn **Next: Add Tags**

![DIY](/images/6-ec2connect/6.4-diy/0008-diy.png)

8. Trong **Add Tags**, Chọn **Next: Configure Security Group**

![DIY](/images/6-ec2connect/6.4-diy/0009-diy.png)

9. Trong **Configure Security Group**

- Chọn **Select an existing security group**
- Chọn **Security Group ID**
- Chọn **Review and Launch**

![DIY](/images/6-ec2connect/6.4-diy/00010-diy.png)

10. Trong **Review Instance Launch**

- Kiểm tra lại và chọn **Launch**

![DIY](/images/6-ec2connect/6.4-diy/00011-diy.png)

11. Trong **Select an existing key pair or create a new key pair**

- Chọn **Proceed without a key pair**
- Chọn **I acknowledge...**
- Chọn **Launch Instances**

![DIY](/images/6-ec2connect/6.4-diy/00012-diy.png)

12. Chọn **View Instances**

![DIY](/images/6-ec2connect/6.4-diy/00013-diy.png)

13. Copy **Instance ID** 

![DIY](/images/6-ec2connect/6.4-diy/00014-diy.png)

14. Trong giao diện **DIY**
-  Dán **Instance ID** vào **VALIDATION FORM**
-  Sau đó, chọn **VALIDATE**

![DIY](/images/6-ec2connect/6.4-diy/00015-diy.png)

15. Sau khi chọn **VALIDATE**

- **VALIDATION MESSAGE** hiển thị **Success!** 
- Sau đó, chọn **EXIT**

![DIY](/images/6-ec2connect/6.4-diy/00016-diy.png)

16. Trong **ASSIGNMENT** chọn **COLLECT**

![DIY](/images/6-ec2connect/6.4-diy/00017-diy.png)

17. Chọn **NEXT**

![DIY](/images/6-ec2connect/6.4-diy/00018-diy.png)

18. Chọn **COLLECT**

![DIY](/images/6-ec2connect/6.4-diy/00019-diy.png)
    
19. Chúc mừng đã hoàn thành Assignment 3

![DIY](/images/6-ec2connect/6.4-diy/00020-diy.png)

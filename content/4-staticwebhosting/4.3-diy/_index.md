{{% notice info %}}

After completing the lab, the player does **DIY**

{{% /notice %}}

1. In the **Practice** interface

- Select **DIY**

![DIY](/images/4-staticwebhosting/4.4-diy/0001-diy.png)

2. In the **DIY** interface

- Read **DIY ACTIVITIES**
- Read **SOLUTION VALIDATION METHOD**

![DIY](/images/4-staticwebhosting/4.4-diy/0002-diy.png)

3. In the **AWS Console** interface

- Find **S3**
- Select **S3**

![DIY](/images/4-staticwebhosting/4.4-diy/0003-diy.png)

4. In the **Amazon S3** interface

- Select **Buckets**
- Select **lab-unique-name-1**
- Select **index.html**
- Select **Actions**
- Select **Rename object**

![DIY](/images/4-staticwebhosting/4.4-diy/0004-practice.png)

5. In the **Rename object** interface

- Change **index.html** to ```waves.html```
- Select **Save changes**

![DIY](/images/4-staticwebhosting/4.4-diy/0005-diy.png)

6. In the **Amazon S3** interface

- View the result of renaming object
- Select **waves.html**


![DIY](/images/4-staticwebhosting/4.4-diy/0006-diy.png)

7. In the **wave.html** interface

- Select **Properties**
- View **Object URL**
- Copy **Object URL**

![DIY](/images/4-staticwebhosting/4.4-diy/0007-diy.png)

8. In the **DIY** interface

- Paste **Object URL** into **VALIDATION FORM**
- Select **VALIDATE**


![DIY](/images/4-staticwebhosting/4.4-diy/0008-diy.png)

9. In the **DIY** interface

- After selecting **VALIDATE**, **VALIDATION MESSAGE** appears **200 OK. Succcess!...**
- Select **EXIT** to exit


![DIY](/images/4-staticwebhosting/4.4-diy/0009-diy.png)

10. In the city interface

- Select **ASSIGNMENTS**
- Select **COLLECT**

![DIY](/images/4-staticwebhosting/4.4-diy/00010-diy.png)

11. Select **NEXT**


![DIY](/images/4-staticwebhosting/4.4-diy/00011-diy.png)

12. Select **COLLECT**

![DIY](/images/4-staticwebhosting/4.4-diy/00012-diy.png)

13. Congratulations to the player receiving the reward

![DIY](/images/4-staticwebhosting/4.4-diy/00013-diy.png)

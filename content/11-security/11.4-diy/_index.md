{{% notice info %}}

After completing the lab, the player does **DIY**

{{% /notice %}}

1. In the **AWS Console** interface

- Find **IAM**
- Select **IAM**

![DIY](/images/11-security/11.4-diy/0001-diy.png)

2. In the **IAM** interface

- Select **User groups**
- Select **Permissions**
- Find **AmazonEC2ReadOnlyAccess**
- Select **AmazonEC2ReadOnlyAccess**
- Select **Add permissions**

![DIY](/images/11-security/11.4-diy/0002-diy.png)

3. In the **IAM** interface

- in **Add permissions**, select **Attach policies**

![DIY](/images/11-security/11.4-diy/0003-diy.png)

4. In the **IAM** interface

- Find **RDSReadOnlyAccess**
- Select **AmazonRDSReadOnlyAccess**
- Select **Add permissions**

![DIY](/images/11-security/11.4-diy/0004-diy.png)

5. In the **IAM** interface

- Select **User groups**
- Select **Permissions**
- View the **Policy name**

![DIY](/images/11-security/11.4-diy/0005-diy.png)

6. In the **DIY** interface

- Enter ```SupportEngineers```
- Select **VALIDATE**

![DIY](/images/11-security/11.4-diy/0006-diy.png)

7. In the **DIY** interface

- After selecting **VALIDATE**, **VALIDATION MESSAGE** appears **You have granted the correct permissions...** is completed **DIY**
- Select **EXIT** to exit

![DIY](/images/11-security/11.4-diy/0007-diy.png)

8. In the city interface

- Select **ASSIGNMENT**
- Select **COLLECT**

![DIY](/images/11-security/11.4-diy/0008-diy.png)

9. Select **NEXT**

![DIY](/images/11-security/11.4-diy/0009-diy.png)

10. Select **COLLECT**

![DIY](/images/11-security/11.4-diy/00010-diy.png)

11. Congratulations to the award winning player

![DIY](/images/11-security/11.4-diy/00011-diy.png)

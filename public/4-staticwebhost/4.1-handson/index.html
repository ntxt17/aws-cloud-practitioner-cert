AWS Cloud Quest > A1 - Static web hosting > Static web hosting

Static web hosting

Steps to perform the Assignment

  1. Select the icon as shown

  1. In Assignment
  • Cloud Computing Essentials select CONTINUE

  1. Learn
  • Select and watch videos in turn: VIDEO CONCEPTS, Amazon S3, AWS

  1. Select the left and right arrows to view Diagram Steps
  2. Select 2 Plan

  1. Plan
  • Check out Practice Lab Goals
  • Check out DIY Goals
  1. Select 3 Practice

  1. Practice
  • Select START LAB

  1. Select Open AWS Console

  1. Use the arrows to see the steps
  2. Select Lab Files

  1. After selecting Lab Files, download labcode.zip.

  1. After downloading labcode.zip, extract the files

  1. Go to the AWS console page opened in step 9, find S3 and select

  1. In the Amazon S3 interface, select Create bucket

  1. In the Create bucket page

  • General configuration, Bucket name enter lab-unique-name-123
  • *AWS Region, select US East (N. Virginia) us-east-1

Bucket name must be unique, if you have done this lab but haven’t passed the challenge, you must do it again for the second time with a different name lab-unique-name-123

  1. In Object Ownership, select ACLs enabled
  2. Under Object Ownership, select Object writer

  1. In Block Public Access settings for this bucket, uncheck Block all public access and select I acknowledge that the current settings might result in this bucket and the objects within becoming public.

  1. In Default encryption
  • Server-side encryption, select Enable
  • Encryption key type, select AWS Key Management Service key (SSE-KMS)

  1. Select Create bucket

  1. Select View Details to view details
  2. Select Upload

  1. Select Add files, add the extracted files. Then select Upload

  1. View successful upload results and select Close

  1. Select Properties

  1. In Static website hosting, select Edit

  1. In Edit static website hosting, we do the steps
  • Static website hosting, select Enable
  • Hosting type, select Host a static website
  • Index document, enter index.html

  1. Select Save changes

  1. Select Permissions
  2. In Bucket policy, select Edit

  1. Copy Bucket ARN and delete Policy

  1. Open policy.txt and replace your Bucket ARN

  2. Copy the contents of the file policy.txt and paste it in Policy

  1. Check again and select Save changes

  1. Select Properties
  2. In Static website hosting, copy Bucket website endpoint

  1. Open browser and paste Bucket website endpoint, get results

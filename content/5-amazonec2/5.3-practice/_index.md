- Read step 2 of **Cloud First Steps**


![Practice](/images/5-amazonec2/5.3-practice/0003-practice.png)

- Find EC2 service and select


![Practice](/images/5-amazonec2/5.3-practice/0004-practice.png)

- Select the arrow to the right to view and take the next step

![Practice](/images/5-amazonec2/5.3-practice/0005-practice.png)


6. Go to **AWS Console** page

- Select **EC2 Dashboard**
- Select **Launch instance**

![Practice](/images/5-amazonec2/5.3-practice/0006-practice.png)

7. Read step 4 of **Cloud First Steps**

![Practice](/images/5-amazonec2/5.3-practice/0007-practice.png)

8. Go to **AWS Console** page

- Select **Amazon Linux 2 AMI**

![Practice](/images/5-amazonec2/5.3-practice/0008-practice.png)

9. Read step 5 of **Cloud First Steps**

![Practice](/images/5-amazonec2/5.3-practice/0009-practice.png)

10. Go to **AWS Console** page

- **Choose an Instance Type**, select **t2.micro**
- Select **Next: Configure Instance Details**


![Practice](/images/5-amazonec2/5.3-practice/00010-practice.png)

11. Read step 6 of **Cloud First Steps**

- Select **Lab Files**

![Practice](/images/5-amazonec2/5.3-practice/00011-practice.png)

![Practice](/images/5-amazonec2/5.3-practice/00012-practice.png)

13. Read step 7 of **Cloud First Steps**

![Practice](/images/5-amazonec2/5.3-practice/00013-practice.png)

14. Go to **AWS Console**

- Select **VPC**
- Select **Subnet**

![Practice](/images/5-amazonec2/5.3-practice/00014-practice.png)

15. Read step 8 of **Cloud First Steps**

![Practice](/images/5-amazonec2/5.3-practice/00015-practice.png)

- In **Advanced Details**, select **As file**
- Select **Select file**, and load the file **user-data**
- Then, select **Next: Add Storage**


![Practice](/images/5-amazonec2/5.3-practice/00016-practice.png)

17. Read step 9 of **Cloud First Steps**

![Practice](/images/5-amazonec2/5.3-practice/00017-practice.png)

18. Select **Next: Add Tags**

![Practice](/images/5-amazonec2/5.3-practice/00018-practice.png)

19. Read step 10 of **Cloud First Steps**

![Practice](/images/5-amazonec2/5.3-practice/00019-practice.png)

20. Select **Next: Configure Security Group**

![Practice](/images/5-amazonec2/5.3-practice/00020-practice.png)

21. Read step 11 of **Cloud First Steps**

![Practice](/images/5-amazonec2/5.3-practice/00021-practice.png)

22. Create a security group

- **Security group name**, enter ```Security-Group-Lab```
- **Description**, enter ```HTTP Group Lab```
- **Rule**, select **HTTP**
- Select **Review and Launch**

![Practice](/images/5-amazonec2/5.3-practice/00022-practice.png)


23. Read step 12 of **Cloud First Steps**

![Practice](/images/5-amazonec2/5.3-practice/00023-practice.png)

24. Double check and select **Launch**

![Practice](/images/5-amazonec2/5.3-practice/00024-practice.png)

25. Read step 13 of **Cloud First Steps**

![Practice](/images/5-amazonec2/5.3-practice/00025-practice.png)

26. Select **Proceed without a key pair**

- Select **I acknowledge...**
- Select **Launch Instances**

![Practice](/images/5-amazonec2/5.3-practice/00026-practice.png)

27. Read step 14 of **Cloud First Steps**

![Practice](/images/5-amazonec2/5.3-practice/00027-practice.png)

28. Select **View Instance**

![Practice](/images/5-amazonec2/5.3-practice/00028-practice.png)

29. Read step 15 of **Cloud First Steps**

![Practice](/images/5-amazonec2/5.3-practice/00029-practice.png)

30. Select the **Amazon EC2 instance** just created

- Find and copy **Public(IPv4) DNS name**

![Practice](/images/5-amazonec2/5.3-practice/00030-practice.png)

![Practice](/images/5-amazonec2/5.3-practice/00031-practice.png)
